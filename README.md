# SQLite 管理台

用于管理服务器上的 SQLite 数据库文件：登记已有数据库或上传 SQLite 文件，浏览和编辑数据记录，查看及编辑表设计。

## 环境要求

- Node.js `>= 22.5.0`
- npm

## 安装与启动

```powershell
npm install
npm start
```

服务默认监听：`http://localhost:3000`

开发模式：

```powershell
npm run dev
```

## 登录配置

启动前，在项目根目录的 `auth.json` 中配置登录账号和密码：

```json
{
  "username": "your-admin-account",
  "password": "use-a-strong-password"
}
```

`auth.json` 已被 `.gitignore` 忽略，不会被提交到仓库。请使用强密码，并妥善保管该文件。

登录成功后，服务会建立一个 HttpOnly 会话 Cookie。未登录访问管理页面会跳转到登录页；未登录调用管理 API 会返回 `401`。

## 数据库登记

登录后点击“登记数据库”，填写显示名称，并选择以下一种来源：

### 填写服务器路径

可填写绝对路径或相对路径，例如：

```text
D:\data\orders.sqlite
```

```text
data\orders.sqlite
```

相对路径会按服务启动时的当前工作目录解析。登记记录会保留原始输入；只有在检查数据库可用性、打开数据库或执行数据操作时才解析实际路径。

### 上传本地 SQLite 文件

支持：`.db`、`.db3`、`.sqlite`、`.sqlite3`。

选择文件不会立即上传。只有点击“登记并打开”时，文件才会连同显示名称一起以表单方式提交。服务端会：

1. 限制上传文件最大为 50MB；
2. 校验扩展名和 SQLite 文件头；
3. 尝试打开数据库验证格式；
4. 保存至服务端受控的 `data/uploads` 目录；
5. 自动登记该上传文件。

## 数据管理

- 浏览数据表、分页查询和搜索记录；
- 对有主键的数据表新增、编辑和删除记录；
- 支持修改主键值：系统使用旧主键定位记录，修改时会二次确认；
- 如果主键被其他表外键引用，系统会拒绝修改该主键值；
- 没有主键的数据表以只读方式展示，避免误修改多行数据。

## 表设计编辑

点击数据表区域的“编辑表设计”，可进行：

- 新增或删除字段；
- 重命名字段；
- 修改字段类型；
- 调整主键、非空约束和默认值；
- 保留原字段数据并迁移到新结构。

保存表设计会在事务中重建数据表。请在操作前备份数据库。

以下复杂表结构不会在界面中修改，以防止约束被静默破坏：

- 虚拟表；
- 包含唯一约束、检查约束、外键、排序规则或生成列的表；
- 被其他表外键引用的键字段不能删除、重命名、修改类型或取消主键。

其他未被引用的字段可以正常编辑。

## 取消登记

- 通过“填写服务器路径”登记的数据库：仅移除登记记录，不会删除原文件；
- 通过“上传本地文件”登记的数据库：取消登记时会删除服务端 `data/uploads` 中对应的上传文件；
- 服务端会同时验证登记来源和文件是否位于受控上传目录，避免删除外部数据库文件。

## 测试

```powershell
npm test
```

测试覆盖登录认证、上传和路径登记、相对路径解析、上传文件清理、记录增删改查、表结构编辑、主键修改及外键保护等场景。
